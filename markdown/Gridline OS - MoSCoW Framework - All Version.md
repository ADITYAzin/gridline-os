# FieldOps — MoSCoW Framework v1.0

> **Status:** Final Baseline  
> **Scope:** MVP v1.0  
> **Rule:** Fitur di luar MUST tidak masuk MVP kecuali ada keputusan product baru.

---

## 1. MUST HAVE — MVP v1.0

### A. Core Job Management

- Login & Role Management
- Customer Management
- Quick Ticket
- Job Management
- Work Order
- Technician Assignment
- Scheduling & Calendar
- Visual Dispatch Board
- Conflict Alert
- Job Status Tracking

### B. Technician Workflow

- My Jobs
- Job Detail
- GPS Check-in / Check-out
- SOP Checklist
- Before / After Photo
- E-Signature
- Work Report

### C. Management

- Basic Admin Dashboard
- Basic Owner Dashboard
- Basic Job & Technician Monitoring

### Core Workflow

```text
Customer
→ Job
→ Schedule
→ Assign
→ Execute
→ Document
→ Verify
→ Complete
→ Monitor
```
